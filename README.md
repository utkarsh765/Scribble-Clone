# Scribble Clone

A multiplayer drawing and guessing game made to learn real-time communication using Socket.IO.

Players can create rooms, join with a code, draw on a shared canvas, and guess words in real time.

This project was mainly built to practice:
- WebSockets / Socket.IO
- Real-time canvas synchronization
- Multiplayer room management
- React state handling
- Backend event handling
- Full-stack deployment

---

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Zustand
- Socket.IO Client

### Backend
- Node.js
- Express
- Socket.IO
- Prisma
- SQLite

---

## Features

- Create and join private rooms
- Real-time drawing canvas
- Brush and eraser tools
- Multiple colors and brush sizes
- Turn-based gameplay
- Random word selection
- Live chat + guessing system
- Scoreboard system
- Round timer
- Multiplayer synchronization
